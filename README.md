# State-triggered cooperative mandatory merging

Data and source code for *State-triggered cooperative mandatory merging at temporary lane closures in mixed traffic flow* by Jie Yu, Tao Chen, Qiang Wen and Mingyuan Bai.

Download [S1 File, version 2.0.1](https://github.com/John-von/state-triggered-mandatory-merging-data/releases/tag/v2.0.1). The release asset `S1_Source_Code_and_Data.zip` is identical to the manuscript's S1 File. `S1_SHA256SUMS.txt` verifies the archive.

The package contains the MATLAB simulator, 3100 experiment records, statistical analyses, timing measurements, representative trajectories and figure-reproduction scripts. See the [reproduction guide](revision_v2/README.md) for requirements and commands. Browse the [core simulator](revision_v2/analysis_scripts/code/), [robustness and component experiments](revision_v2/round2_analysis/) and [plotting scripts](revision_v2/figure_reproduction/). Download the release for the complete archive, including binary MAT records.

Version 2.0.1 simplifies documentation and code comments, removes redundant files and corrects the statistics entry point. Simulation data and results are unchanged.

Earlier releases and the original top-level `data/`, `figures/` and `scripts/` remain available. Use the latest S1 release for the revised manuscript.
