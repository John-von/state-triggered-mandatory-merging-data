# Main experiments

`data/raw/` contains 1500 main runs and 80 safety-ablation runs. `data/summary/` contains aggregated and paired results, and `data/trajectories/` contains representative trajectories. See `DATA_DICTIONARY.md` for variables and units, and the archive-root README for simulation and plotting commands.

The main grid uses five target-lane densities and five nominal CAV penetrations. For 26 target-lane vehicles, penetrations 0%, 25%, 50%, 75% and 100% correspond to 0, 7, 13, 20 and 26 CAVs. Each condition uses paired seeds 0-19.
